# 本机与一键部署版同步

本机修改时同步更新一键部署源代码，用户明确要求推送时才执行 Git 提交和推送。

配置本机专用的 `.local/live-sync.json`（此文件不会提交）：

```json
{
  "liveRoot": "本机 NAS 根目录的绝对路径",
  "sourceRoot": "本机修改后的 SFTPGo 源码绝对路径",
  "upstreamRoot": "固定版本、未打补丁的 SFTPGo 源码绝对路径"
}
```

运行 `node tools/sync-live.cjs` 同步；`--check` 仅检查合并，不写入结果。第一次运行会建立本机源码基线。后续按基线做三方合并，保留部署版的路径和平台差异；冲突会在写入部署文件之前报错。管理的资源由现有 overlay 和头像目录组成；新增资源或原生补丁文件需加入同步范围。不要删除 `.local/live-sync-baseline` 后继续增量同步。

工具只同步受管理的页面、静态资源、扩展和原生代码补丁，不复制运行数据、账号、密钥、证书、可执行文件或隧道配置，也不会提交或推送 GitHub。发布前仍需运行测试、应用到干净源码验证并编译。
